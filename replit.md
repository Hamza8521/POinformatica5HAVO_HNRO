# Project overview

This is a static p5.js creative-coding sketch. The page is defined by `index.html`, styling lives in `style.css`, and the drawing code lives in `script.js`. Image assets are stored in `images/`.

## Running on Replit

Use the **Run** button to start the `Serve static` workflow, then open Preview.

No dependency installation, environment variables, or secrets are required. The browser loads p5.js 1.6.0 from jsDelivr, so the sketch needs internet access when the page first loads.

Changes to the HTML, CSS, JavaScript, or images are served automatically; refresh Preview to see them.
